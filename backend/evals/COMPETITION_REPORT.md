# Model competition: three real datasets

Generated by `python -m evals.model_competition` and `python -m evals.competition_report`. None of the datasets is Indian; these results say nothing yet about accuracy in Indian shops.

**Protocol.** Every candidate sees exactly the same history at each forecast origin. The winner is the single configuration with the best mean (over the three datasets) of weekly WAPE relative to a 28-day moving average on the VALIDATION windows; the later TEST windows were never used for choosing and are reported below. LightGBM and XGBoost settings were fixed before the first run.

**Winner: `ens_xgb_ses_75`** (75% XGBoost Tweedie + 25% smoothing).
